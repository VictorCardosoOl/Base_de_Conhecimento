# Colaboradores

Quem participa deste projeto e as origens que recebem crédito, com base no histórico do Git e nos arquivos
publicados no repositório.

## Gráfico de colaboradores

O GitHub mostra as contribuições em
[github.com/VictorCardosoOl/Base_de_Conhecimento/graphs/contributors](https://github.com/VictorCardosoOl/Base_de_Conhecimento/graphs/contributors).
O gráfico considera apenas os commits da branch padrão: contribuições feitas em outras branches aparecem
nele depois do merge.

## Créditos e origens

- **Base de Conhecimento original:** [VictorCardosoOl/Base_de_Conhecimento](https://github.com/VictorCardosoOl/Base_de_Conhecimento),
  de onde vêm a aplicação, os artigos e o site publicado. A versão anterior ao monorepo é o commit `4e4fade`.
- **Projeto de origem do AuthService:** [https-shini/AuthService](https://github.com/https-shini/AuthService),
  usado como base do serviço de identidade. Os guias e imagens desse projeto continuam em
  [`AuthService/read-model/`](./AuthService/read-model), como referência histórica, com a licença dele.

## Como ser listado

Contribuições entram por Pull Request, seguindo o [CONTRIBUTING.md](./CONTRIBUTING.md). Quem contribuir pode
pedir a inclusão neste arquivo no próprio Pull Request, indicando o handle do GitHub e o que fez.
